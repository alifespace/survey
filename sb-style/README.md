# SB Style

一套面向开发者产品、SaaS 工具和技术官网的原创设计风格包。它借鉴成熟开发者工具的设计原则，但不包含 Supabase 的商标、Logo、原始文案或专属品牌资产。

## 包含内容

- `docs/`：设计方向、令牌、组件、首页架构、文案动效和实施验收规范。
- `demo/index.html`：营销首页 Demo。
- `demo/dashboard.html`：可交互的产品 Dashboard Demo。
- `demo/styles.css`、`demo/dashboard.css`：营销页与控制台样式。
- `demo/script.js`、`demo/dashboard.js`：主题、导航、数据筛选、新增记录、导出等交互。

## 本地查看

直接用浏览器打开：

- `demo/index.html`
- `demo/dashboard.html`

也可以在当前目录启动任意静态文件服务器。

Demo 中的产品名称、客户、指标和业务数据均为虚构演示内容。压缩包不包含部署身份、凭据、Git 元数据或运行环境配置。
