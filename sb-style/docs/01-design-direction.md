# 设计方向

## 一句话定义

这是一个“像优秀开发工具一样清晰”的产品官网：深色而不压抑，技术感强但不炫技，信息密度高但始终易读。

## 从 Supabase 提炼出的设计 DNA

### 1. 产品本身就是主视觉

不依赖抽象 3D 球体或大面积装饰插画。优先展示真实界面、代码、查询结果、日志、图表和状态变化，让访客在首屏之后立刻看见产品如何工作。

### 2. 单一强调色建立识别

页面大部分由中性色构成，绿色只出现在品牌焦点、主要操作、活动状态、代码高亮和少量环境光中。强调色越少，关键操作越醒目。

### 3. 边框承担结构，阴影只表达层级

卡片之间主要靠 1px 边框、背景明度差和留白区分。阴影不用于日常装饰，只用于悬浮层、菜单和需要离开页面平面的内容。

### 4. 营销页拥有工具感

标签页、代码窗口、终端、表格和状态点把产品体验带进营销页面。交互应当可理解、可操作，不做只能观看的“假 UI”。

### 5. 文案短，证据紧跟承诺

标题先表达用户结果，正文补充实现方式。每个重要承诺后应尽快出现产品实景、指标、客户案例或可运行示例。

## 视觉关键词

- 精确：对齐严格，尺寸和间距可预测
- 克制：避免多彩渐变、厚重阴影和过度圆角
- 开放：大块留白与通透分隔，避免卡片套卡片
- 工程感：代码、网格、状态、数据和真实产品界面
- 可信：使用具体功能和事实，不使用空泛的“革命性”措辞

## 原创转译原则

可以借鉴：

- 深浅主题的分层逻辑
- 中性色主体加单一绿色强调色
- “能力卡片 + 产品演示”的叙事方法
- 细边框、紧凑控件和开发工具式组件
- 简短直接的开发者文案

不要复制：

- Supabase Logo、闪电符号和品牌资产
- 原站标题、产品描述、客户引语或插画
- 完全相同的色值组合、页面顺序和卡片构图
- 让用户误以为本项目属于或获得 Supabase 官方背书的表达

## 推荐的差异化抓手

至少选择两项建立自己的识别：

1. 自有强调色。可以保留绿色家族，但调整色相、饱和度和明度。
2. 自有图形母题。例如轨道、节点、数据脉冲、像素矩阵或等高线。
3. 自有标题字体。正文保持易读，标题可使用更有性格的字体。
4. 自有产品演示语言。围绕你的核心对象设计表格、画布、时间线或对话界面。
5. 自有内容节奏。首页结构由用户任务决定，不照搬参考站顺序。

## 设计判断顺序

遇到视觉分歧时，按以下顺序决策：

1. 用户是否更快理解产品价值？
2. 主要操作是否更容易发现？
3. 内容是否在移动端仍可扫描？
4. 是否保持一套一致的令牌和组件？
5. 最后才考虑它是否“更像参考站”。
