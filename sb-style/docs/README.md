# Supabase-inspired web design brief

这是一套面向开发者产品、SaaS 工具和技术型官网的设计文档。它研究了 Supabase 官网与公开设计系统，并将其视觉方法转译为一套独立、可实施的规范。

> 目标是借鉴 Supabase 的设计原则，而不是复制其商标、Logo、页面文案或独有插画。

## 快速决策

- 默认主题：深色优先，同时保留完整浅色令牌
- 主要气质：克制、可信、技术感、可操作
- 重点元素：高对比标题、单一绿色强调色、细边框、代码与产品实景
- 页面密度：首屏宽松，产品演示区偏紧凑，长页通过边框和留白建立节奏
- 推荐技术：语义化 HTML、CSS variables、任意组件框架；可选 Tailwind CSS
