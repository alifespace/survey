以下数值是本项目的原创起点，不是 Supabase 官方令牌的复制。令牌采用语义命名，组件不得直接依赖某个颜色名称。

### 使用规则

- 大面积背景只用中性色，强调色面积建议不超过首屏可视面积的 8%。
- “成功”与“品牌强调”必须是两个语义令牌，即使初始色值相近。
- 普通正文与背景的对比度至少为 `4.5:1`，大字号文字至少为 `3:1`。
- 禁用态通过颜色和控件状态共同表达，不能只降低到难以辨认的透明度。

## 字体

推荐使用开放字体，避免依赖参考品牌的商业字体。

```css
:root {
  --font-heading: "Manrope", "Inter", system-ui, sans-serif;
  --font-body: "Inter", system-ui, sans-serif;
  --font-mono: "Source Code Pro", "SFMono-Regular", Consolas, monospace;
}
```

| 角色 | 桌面字号/行高 | 移动字号/行高 | 字重 |
| --- | --- | --- | --- |
| Hero | `72/72` | `44/46` | 500 |
| H1 | `52/56` | `38/42` | 500 |
| H2 | `38/44` | `30/36` | 500 |
| H3 | `24/32` | `22/30` | 500 |
| Lead | `20/30` | `18/28` | 400 |
| Body | `16/26` | `16/26` | 400 |
| UI | `14/20` | `14/20` | 500 |
| Caption | `12/18` | `12/18` | 500 |
| Code | `13/21` | `12/19` | 400 |

规则：

- 用字号和留白建立层级，不依赖大量粗体。
- Hero 最多三行，理想状态为两行。
- 正文行宽控制在 55–72 个英文字符；中文建议 28–38 个汉字。
- 仅代码、快捷键、技术标签使用等宽字体。

## 间距与尺寸

采用 4px 基础网格：

```text
space-1  4px      space-6   24px
space-2  8px      space-8   32px
space-3  12px     space-10  40px
space-4  16px     space-12  48px
space-5  20px     space-16  64px
space-20 80px     space-24  96px
```

- 页面最大宽度：`1280px`
- 阅读内容最大宽度：`720px`
- 桌面页边距：`32px`；平板：`24px`；手机：`20px`
- 区块纵向间距：桌面 `112–144px`；手机 `72–96px`
- 导航高度：桌面 `64px`；手机 `56px`
- 按钮高度：`36px / 40px / 44px`
- 最小触控区域：`44 × 44px`

## 圆角、边框和阴影

```css
:root {
  --radius-sm: 6px;
  --radius-md: 8px;
  --radius-lg: 12px;
  --radius-xl: 16px;
  --border-width: 1px;
  --shadow-float: 0 16px 48px rgb(0 0 0 / 0.28);
}
```

- 按钮与输入框使用 `6–8px`，卡片使用 `8–12px`。
- 避免所有容器都使用圆角；整宽区块和数据表可保持直角。
- 静态卡片默认无阴影。
- 环境光可使用低透明度径向渐变，但不能影响文本对比度。

## 响应式断点

| 名称 | 宽度 | 主要变化 |
| --- | --- | --- |
| `sm` | `640px` | 双按钮可横排 |
| `md` | `768px` | 导航展开，部分双栏出现 |
| `lg` | `1024px` | Hero 与产品演示使用完整构图 |
| `xl` | `1280px` | 内容达到最大宽度 |

采用内容驱动断点。组件在内容挤压时提前换行，不为凑断点保留拥挤布局。
